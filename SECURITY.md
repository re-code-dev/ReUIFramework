# Security Policy

## Supported versions

Security fixes are applied to the current maintained Re:UI branch.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities that could affect servers, expose sensitive data or enable abuse.

Contact the maintainers privately with:

- affected version;
- reproduction steps;
- impact;
- proof of concept where safe;
- suggested mitigation if known.

Allow maintainers reasonable time to investigate before public disclosure.

## Scope

Relevant issues include:

- unsafe server/client trust boundaries;
- privilege or admin-control bypasses;
- arbitrary command execution;
- insecure network payload handling;
- malicious configuration or data parsing.

Ordinary crashes and visual bugs should use the standard bug template.
