# FAQ

## Is Re:UI a complete vanilla UI replacement?

No. It is a framework for building interfaces. Vanilla replacement projects can be built on top of it.

## Which Project Zomboid version is targeted?

Build 42.20 is the primary target.

## Does Re:UI support Build 41?

No.

## Why use a compatibility layer?

It keeps Build-specific changes away from controls and reduces migration work.

## Can the showcase open automatically?

No. It should only open through an explicit developer action.

## Where should bugs be reported?

Use the GitHub bug report template and include the relevant log excerpt.
