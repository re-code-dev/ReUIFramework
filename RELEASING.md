# Release Process

1. Confirm target Project Zomboid build.
2. Remove legacy and duplicate files.
3. Run static checks.
4. Run the full in-game showcase test.
5. Test repeated open/close behavior.
6. Test multiple resolutions.
7. Test keyboard and mouse input.
8. Test controller paths where supported.
9. Test multiplayer client behavior.
10. Test dedicated server startup.
11. Update version metadata.
12. Update `CHANGELOG.md`.
13. Create a clean release archive.
14. Verify archive paths.
15. Publish release notes with known limitations.

Release archives must not contain development logs, editor state or duplicate nested mod folders.
