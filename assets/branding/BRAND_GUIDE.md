# Re:UI Brand Guide

## Name

Use `Re:UI` with this capitalization and punctuation.

## Core colors

| Role | Hex |
|---|---|
| Background | `#050812` |
| Surface | `#0E1728` |
| Elevated surface | `#111F35` |
| Border | `#27405F` |
| Primary blue | `#2563EB` |
| Light blue | `#60A5FA` |
| Primary text | `#F8FAFC` |
| Muted text | `#94A3B8` |

## Logo clear space

Keep clear space around the logo equal to at least 12% of its width.

## Do not

- stretch the logo;
- recolor it with random gradients;
- place it on a low-contrast background;
- change the `Re:UI` spelling;
- combine it with unrelated icon styles.
